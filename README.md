# Habit Tracker Application

A simple, effective, and intuitive web-based application designed to help users establish positive routines, track daily progress, and maintain consistent long-term habits.

---

## Core Features

- **Daily Habit Tracking:** Easily create, complete, and log daily habits.
- **Streak & Analytics:** Monitor continuous streaks to keep yourself motivated and consistent.
- **Categorization:** Organize habits by categories (e.g., Health, Productivity, Personal Growth).
- **Responsive Dashboard:** Optimized for a seamless experience on both mobile devices and desktop screens.

---

## Tech Stack & Architecture

* **Frontend:** HTML5, CSS3, JavaScript (DOM manipulation & client-side state tracking)
* **Backend:** Node.js / Express or Java Spring Boot (REST APIs)
* **Database / Storage:** LocalStorage / SQL (schema for habit entries and user logs)

---

## Getting Started

### Prerequisites

Ensure you have the following installed on your local development setup:

* **Node.js** (v16+) or relevant runtime environment
* **Git**

---

### Setup & Installation

#### 1. Clone the Repository

```bash
git clone [https://github.com/Manoj-pamidimukkkala/HABBIT-TRACKER.git](https://github.com/Manoj-pamidimukkkala/HABBIT-TRACKER.git)
cd HABBIT-TRACKER

```

#### 2. Install Dependencies (if applicable)

```bash
npm install

```

#### 3. Run the Development Server

```bash
npm start

```

#### 4. Launch the App

Open `index.html` directly in your browser or navigate to `http://localhost:3000`.
